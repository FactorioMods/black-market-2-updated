Temporary migration bridge for Black Market 2.

Replace the original BlackMarket2 ZIP with this bridge and enable black-market-2-updated alongside it. Load an existing save and save under a new filename. The updated fork imports the old storage, including credits and orders. Remove the bridge after that save. Never load a save with only this bridge: it deliberately defines no entities.
