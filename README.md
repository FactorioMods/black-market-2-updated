# Black Market 2: Updated

Buy and sell items, fluids and electricity through trading chests, tanks and accumulators.

**Factorio 2.1 · Version 1.0.3**

- Automatic orders with configurable trading frequency and fees.
- Credits and prices shared through the market.

## Installation

Disable BlackMarket2 before enabling this fork. To keep an old market balance and orders, first use the temporary migration bridge, save under a new filename, then remove the bridge. Without that import, the old mod’s private financial data cannot be recovered automatically.
